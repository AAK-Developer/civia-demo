# CivIA — demo GovTech

Proyecto demostrativo completo para presentar CivIA a ayuntamientos.

## Incluye
- Landing comercial responsive.
- PWA ciudadana instalable.
- Panel web municipal.
- Datos de demostración.
- Despliegue automático en GitHub Pages.

## Ejecutar en local
```bash
npm install
npm run dev
```

## Publicar en GitHub Pages
1. Crear repositorio público.
2. Subir el contenido de esta carpeta.
3. En Settings → Pages, seleccionar **GitHub Actions**.
4. Hacer push a `main`.

## Importante
Esta versión usa datos simulados. No contiene backend, autenticación real ni integración con sistemas municipales.
